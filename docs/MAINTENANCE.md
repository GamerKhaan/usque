# Maintenance scope

This public fork is maintained by GamerKhaan.ir at
<https://github.com/GamerKhaan/usque>. It adds an Ubuntu service profile,
supervision, deployment tools, and narrowly scoped reliability patches to
[Diniboy1123/usque](https://github.com/Diniboy1123/usque).

Initial upstream base: `v4.2.1`, commit
`6aa03fc97d12848dce34eedbd187fb1077b5d1ea`.

The original Git history, module path, and MIT copyright notice are preserved.
Maintenance of this fork does not imply authorship of upstream code.
Production releases are cut from reviewed fork commits; upstream releases are
never merged or deployed automatically.

Release support starts with Ubuntu Linux on amd64 and arm64. A successful
build is not evidence of a successful live WARP deployment. Acceptance results
must identify the environment and exact release tested.
